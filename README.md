# MD Hamim Reza — Personal Portfolio

A responsive, modern personal portfolio website for MD Hamim Reza.

## Included
- Responsive single-page portfolio
- About, Skills, Projects, Education and Contact sections
- Mobile navigation
- Scroll reveal animations
- Reading progress bar
- SEO metadata
- GitHub project link
- No build step required

## Customize
1. Put your professional photo at `assets/profile.jpg`.
2. Update LinkedIn and other social links in `index.html`.
3. Add new projects inside the `#projects` section.
4. Push the files to GitHub.
5. Deploy the repository with Vercel or GitHub Pages.
